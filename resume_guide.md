## 📋 How to Convert HTML to PDF

### Option 1: Chrome/Edge Browser (Easiest)
1. Open `ATS_Resume_Lokesh_Reddy.pdf.html` in Chrome or Edge
2. Press **Ctrl+P** (or **Cmd+P** on Mac)
3. Click "Save as PDF"
4. Save as `Lokesh_Reddy_Resume.pdf`

### Option 2: Online Converter
1. Go to https://convertio.co/html-pdf/
2. Upload `ATS_Resume_Lokesh_Reddy.pdf.html`
3. Download as PDF

### Option 3: Command Line
```bash
# Using wkhtmltopdf (install first)
wkhtmltopdf ATS_Resume_Lokesh_Reddy.pdf.html Lokesh_Reddy_Resume.pdf
```
